# REQ-0001 — Gated agent workforce for trustworthy AI software

**Product:** Definition of Done (formerly working title "SDLC Agents"; renamed 2026-11-06 —
the agile term is instantly legible to skeptical engineers, states the promise, and is free
on GitHub (`definition-of-done`), PyPI, and npm)

---

## 1. Problem

AI coding tools turn ideas into useful-looking prototypes in hours. Those prototypes grow into
real apps with no architecture, no tests, no docs, and no record of why anything exists.
The first serious change request exposes software nobody — human or agent — can safely modify.

The same failure hits two groups from opposite sides:

| Group | What they feel today |
| --- | --- |
| Non-technical vibe coders | The demo worked; the app is now unfixable. They cannot see the debt forming and have no way to pay it down. |
| Seasoned software engineers | They do not trust agent output. Reviewing code they never asked for costs more than writing it themselves, so they opt out of the productivity entirely. |

Existing tools optimize generation speed. Nothing free and open enforces *engineering
discipline* on top of any agent, so the market gets fast prototypes and slow disasters.

## 2. Human job to be done

| Job | In the user's words |
| --- | --- |
| JTBD-1 (vibe coder) | "Turn my idea into software that can still be safely changed in six months, without me becoming a software engineer." |
| JTBD-2 (engineer) | "Make agents produce software to engineering standards — specified, tested, traceable — so I can approve work instead of redoing it." |

## 3. Value proposition

**A free, open-source, vendor- and model-agnostic agent workforce that forces AI coding
through the proven software engineering pipeline — intent, architecture, use cases, behavior
contracts, tests, code, review, docs — on whatever harness the user already runs.**

- Vibe coders get prototypes that stay alive: every line traces back to an approved intent.
- Engineers get auditability: gates, not vibes, decide what merges; the diff is explainable.
- The industry gets a shared standard: the artifact chain (AGENTS.md) is the product, not a lock-in.

## 4. Constraints (set by the human owner, 2026-11-06)

1. Open source, free for community use, built for the betterment of the industry.
2. Vendor- and model-agnostic: usable from Claude Code by a non-coder, and from a
   homegrown local stack by an LLM enthusiast.
3. Harness-agnostic substrate: artifacts and gates are the product; agent runtimes are pluggable.

## 5. Launch message

> "Stop shipping tomorrow's unmaintainable mess. Definition of Done is a free, open workforce
> of engineering agents that turns AI prototypes into auditable software — same speed, real
> engineering, any model, any tool. It's the agent team that doesn't stop until the work
> actually meets its definition of done."

## 6. Non-goals

- No paid tier, no hosted service, no telemetry monetization. Free and open, full stop.
- We do not build a model, a coding agent, or a new harness. We orchestrate existing ones.
- We do not remove the human from approval. Agents produce; humans sign off. That is the product.
- We do not promise "no code reading ever." We promise software a human *can* read and explain.

## 7. Market validation (the "no is valid" checklist)

Answer honestly. Any "no" below blocks the pipeline at Stage 0.

- [ ] Do both target groups recognize this failure in their own work, unprompted?
- [ ] Is "free + open + harness-agnostic" a real differentiator, or a nice detail?
- [ ] Would a seasoned engineer adopt the artifact chain as a standard, not just mock it?
- [ ] Is there evidence prototypes-to-zombie-apps is growing, not a fad that fades with model quality?

## 8. Rejected alternatives

| Alternative | Why rejected |
| --- | --- |
| Closed hosted platform | Owner constraint; contradicts "betterment of the industry." |
| Single-harness plugin (e.g., Claude Code only) | Locks out homegrown/local-stack users; fragments the standard. |
| Selling to compliance-heavy enterprises first | Paid wedge, slower; community standard first, value stories later. |
| Pure methodology (docs only, no agents) | Humans won't manually run an eight-stage pipeline; agents make the discipline cheap. |
