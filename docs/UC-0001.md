# UC-0001 — Idea to software that stays changeable

**Persona:** Vera, non-technical vibe coder. **Job (JTBD-1):** "Turn my idea into software
that can still be safely changed in six months, without me becoming a software engineer."

## Context

Vera has an idea and a harness (Claude Code, OpenCode, or a local stack) with `dod`
installed. She wants outcomes, not process. The pipeline runs *for* her: agents draft every
artifact, she approves in plain language at two points — the requirement and the release
(ARCH-0001 §5: mechanical gates, human signoff).

## Scenarios

**S1 [happy] Bootstrap an idea.**
GIVEN Vera describes her idea to her harness in everyday words,
WHEN the Product Analyst role drafts `REQ-0101` for the project (problem, JTBD, value),
THEN Vera sees a one-page requirement she can read aloud, approves it, and only then does
any design or code work begin.

**S2 [happy] Feature requests ride the full chain.**
GIVEN an approved project, WHEN Vera asks for a new feature ("add dark mode"),
THEN agents update the chain in order — requirement delta, use case, spec, and HLD/DD if
the design moves — each stage's gate passes mechanically, the Test Agent generates failing
tests from the spec, the implementer writes code against them, and Vera is asked only to
approve the requirement in plain words and confirm the result matches what she asked for.

**S3 [edge] Prototyping is allowed, quarantined.**
GIVEN Vera wants to "just see if it works", WHEN she asks for a throwaway prototype,
THEN the harness may prompt-to-code on a throwaway branch, but `dod gate` blocks merging
it; the branch is either promoted through the artifact chain or deleted.

**S4 [failure] A shortcut is stopped, not silently allowed.**
GIVEN an agent (or Vera) tries to merge code whose UC or spec is missing or unapproved,
WHEN CI or a local run executes `dod gate --stage N`,
THEN the merge fails with a plain-language reason naming the missing artifact and the role
that produces it — never a stack trace, never a silent pass.

## Out of scope

Teaching Vera engineering concepts; IDE features; hosted dashboards. The artifact chain and
gates are the teacher (REQ-0001 §6 non-goals).
