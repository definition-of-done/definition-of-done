# UC-0006 — The gates don't care who wrote the code

**Persona:** Sam, old-school engineer on a homegrown local stack, no agent workforce.
**Job (REQ-0001 §4):** get the discipline — specs, tests-first, traceability, clean-code
gates — without adopting any vendor's model, harness, or agents at all.

## Context

Sam writes every line by hand on a local model stack he assembled himself, or with no
models at all. He is the far end of the target range ("from the vibiest of vibe coders to
the most traditional old school engineer") and the honesty check on the agnosticism claims
(REQ-0001 §4, constraints 2–3). If the pipeline only works for agent-driven teams, the
substrate is a vendor story in disguise. So the rule is simple: **artifacts and gates are
the product; agents are optional producers.** Sam uses `dod init`, the artifact templates,
and `dod check`/`dod trace` — the same pure gates every agent must pass — and writes the
artifacts and the code himself.

## Scenarios

**S1 [happy] Hand-written code passes the same gates.**
GIVEN Sam hand-authors a REQ, UC, spec, and code with no agent anywhere, WHEN `dod check`
runs the pipeline gates, THEN his change passes exactly what an agent's change must pass —
spec parses, tests exist and pass, trace markers resolve — and nothing in the gate output
assumes a model wrote any of it.

**S2 [happy] The homegrown stack is a first-class harness.**
GIVEN Sam wires `dod` into his own local tooling — scripts, a terminal loop, a self-hosted
model — WHEN the tools exchange nothing but files and exit codes (ARCHITECTURE §8: the
runtime split), THEN the pipeline behaves identically to running under Claude Code or
OpenCode, and no feature requires a specific vendor's runtime.

**S3 [edge] It works with the network unplugged.**
GIVEN Sam's environment is air-gapped, WHEN he runs the full gate suite, THEN every gate
passes or fails on local files alone — gates are deterministic and make no network calls
(ARCHITECTURE §3) — and only role work that needs a model is affected, never verification.

**S4 [failure] Hand-hacked code is caught like an agent orphan.**
GIVEN Sam skips the artifact chain one late Friday and hacks code directly, WHEN `dod trace`
runs, THEN his untraceable code is flagged exactly like an agent's orphan — same report, no
human/agent distinction — and the Golden Rule applies to him verbatim: fix the governing
artifact first, regenerate, resubmit.

## Out of scope

Agent roles Sam does not run (every role is opt-in; the substrate never requires one);
IDE or editor integrations; tooling to help him write artifacts faster (templates and
plain Markdown are the tool).
